# Estructura de Datos - 3er Corte
Repositorio con el Taller 3 (Árboles AVL) y el Parcial 3 (Grafos) de la asignatura Estructura de Datos - Universidad Popular del Cesar.

## Estructura
- `Taller3_AVL/` -> Programa de Aprendizaje de Árboles (PAA)
  - `python/` -> Implementación en Python (PyQt6 + JSON)
  - `cpp/`    -> Implementación en C/C++
  - `docs/`   -> Documentación técnica
- `Parcial3_Grafos/` -> Programa Estadístico de Rutas de Automóviles (PERA)
  - `python/` -> Implementación en Python
  - `cpp/`    -> Implementación en C/C++
  - `docs/`   -> Documentación técnica
